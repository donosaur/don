# Portfolio Standards & Pre-Publish Gate

When modifying or adding case studies, HTML pages, or visual assets in `don.polisti.co`:

1. **Verify rendered result:**
   - Follow `standards.md` and `taste.md` (restraint, no template look, sentence case headings, clean negative space).
   - Use the `browser-verification` skill or check mobile (390px) and desktop (1280px) viewports before finishing.

2. **Metadata hygiene:**
   - Ensure `<title>`, `<meta name="description">`, OpenGraph tags (`og:title`, `og:image`, `og:url`), and Twitter cards match canonical standards via the `metadata-auditor` skill.
   - All `<img>` tags must include descriptive `alt` attributes.
