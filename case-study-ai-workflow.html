the design-to-code loop

How an idea moves to code

A four-stage loop from a brief to a verified component running in the browser.

01. Frame the spec

Spec 
# feature-spec.md
• Goal: responsive video rail
• Focus: D-pad navigation, scale 1.05
• Acceptance: no layout shift on focus
A concise markdown brief with explicit acceptance criteria instead of open-ended prompt vibes.

02. Constrain with taste

Constraints 
# don-os/taste.md
• DO: desaturated, muted + 1 accent
• AVOID: purple/teal gradients, glow
• AVOID: generic SaaS template look
Explicit negative constraints stop models from defaulting to generic AI templates.

03. Build in the medium

Build 
$ agy run --spec feature-spec.md
✓ reading taste.md & standards.md
✓ generating DOM components + CSS
✓ hot-reloading at localhost:8000
Claude Code and Google Antigravity generate functional components and styles directly from the spec.

04. See what shipped

Verify 
# verification check
• Reflow & text-wrap: pretty
• Keyboard focus & visible states
• Verified on desktop & mobile
Check the running page, not the mockup: reflow, focus states, and layout on real devices.
